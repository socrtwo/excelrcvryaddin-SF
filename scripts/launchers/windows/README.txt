Excel Recovery Add-in — Windows
==============================

How to run
----------
1. Unzip this archive anywhere (e.g., your Desktop).
2. Double-click `ExcelRecoveryAddin.bat` to open the app in your default browser.
   - Or open `web\index.html` directly.

Optional: install as a desktop app
----------------------------------
With the page open in Microsoft Edge or Google Chrome, click the install icon
in the address bar (or Settings -> Apps -> Install this site as an app).
You will get a real Start Menu entry that runs offline.

Privacy
-------
Your .xlsx or .xls file never leaves your computer; all processing happens locally
in the browser.

Classic Excel COM add-in
------------------------
The Excel-powered strategies (Open & Repair, Safe Mode, SYLK, ...) are not in
this bundle -- they need Microsoft Excel installed. Build the classic VB.NET
add-in from source: https://github.com/socrtwo/excelrcvryaddin-SF
(open ExcelRecoveryAddin.sln in Visual Studio).
