Excel Recovery Add-in

How it works

An .xlsx workbook is a ZIP archive full of XML. When the file is corrupt, this app first identifies what the bytes really are (separating any concatenated foreign files), then applies the portable strategies of the original add-in:

  1. ZIP Repair — Try — scans the byte stream for ZIP local file headers and re-inflates every salvageable entry with a fault-tolerant DEFLATE decoder, then repackages a fresh, well-formed .xlsx. (The original shelled out to Info-ZIP's zip -FF.)
  2. Extract Data (non-MS) — parses shared strings and xl/worksheets/*.xml directly and writes one CSV per sheet, even when Excel refuses to open the workbook. (The original used the doctotext and coffec tools.)
  3. Salvage Cells — regex-harvests cell references, values and text runs from partially readable XML when the sheets no longer parse.
  4. .xls Text Rescue — best-effort printable-string sweep (ASCII + UTF-16) of a legacy OLE2/BIFF workbook that nothing else will open.

Need the Excel-powered strategies? Use the Windows add-in

Several strategies of the original add-in drive Microsoft Excel itself over COM. They cannot run in a browser and need a Windows machine with Excel installed. The classic VB.NET add-in in this repository still provides them:

  • Open & Repair and Open & Extract Data — Excel's built-in corrupt-load modes (xlRepairFile / xlExtractData)
  • Open in Safe Mode (excel.exe /s /r) and Manual Calculations mode
  • External References — pull values out of a workbook that won't open via link formulas
  • Save As SYLK / Save As HTML — round-trip filtering that discards damaged parts
  • Open with WordPad / Excel Viewer — last-ditch content viewing

Build it from source with Visual Studio — see the README for instructions. Requires Windows and Excel 2003 or later.
